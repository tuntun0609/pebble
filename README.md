# Pebble

Pebble 是一款轻量的 macOS 菜单栏便笺应用，用来随手记录灵感、收藏文字和整理待办。通过浮动面板快速输入，或在其他应用中选中文字后按下快捷键，将内容收进笔记。

使用 SwiftUI 和 AppKit 构建，支持英文与简体中文。笔记自动保存在本机，无需账号，没有云同步或追踪。

## 功能

- **随手记录**：从菜单栏打开浮动面板，输入后按 Return 保存，支持连续添加。
- **选文捕获**：默认双击 Shift 捕获其他应用中的选中文字，也可以自定义全局快捷键。
- **分组整理**：创建和重命名分组，拖动分组排序，拖动笔记排序或移动到其他分组。
- **快速查找**：按笔记内容和分组名称搜索，展开查看长笔记。
- **Markdown 展示**：支持标题、粗体、斜体、链接、行内代码、代码块、引用、列表和分隔线。
- **批量操作**：多选笔记后复制、复制为编号列表、合并、移动、标记完成或删除。
- **灵活编辑**：在卡片内或独立窗口编辑，支持撤销与重做。
- **个性设置**：窗口置顶、浅色或深色外观、跟随系统、登录时启动，以及即时切换界面语言。

## 构建与启动

需要 macOS 14 或更新版本，以及带 macOS SDK 的 Apple Command Line Tools。

在项目目录运行：

```sh
./build.sh
open "build/Pebble.app"
```

构建产物为 `build/Pebble.app`。项目直接使用 `swiftc` 编译，无第三方依赖，不需要完整的 Xcode 工程。构建脚本生成当前 Mac 架构的应用，并使用本地临时签名。

启动后，Pebble 常驻菜单栏，不显示 Dock 图标。点击菜单栏图标，在菜单中选择 **显示 / 隐藏 Pebble** 即可切换面板；隐藏面板不会退出应用。退出请使用菜单中的 **退出 Pebble**。

修改源码后，重新运行构建脚本并重启应用即可。

构建脚本默认生成当前架构、本地临时签名的应用，也可通过环境变量调整（CI 使用）：`VERSION` 注入版本号、`ARCHS="arm64 x86_64"` 生成通用二进制、`SIGN_IDENTITY` 指定签名身份、`ENTITLEMENTS` 指定权限文件。

## 自动发布

推送 `v` 开头的标签（如 `v1.1.0`）即可触发 GitHub Actions（`.github/workflows/release.yml`）自动构建并发布。标签中的版本号会写入 `Info.plist`，是每次发布的唯一来源。流程会在 `macos-latest` 上编译 `arm64 + x86_64` 通用二进制，打包成 `Pebble-<版本>.dmg`（含 `/Applications` 拖拽安装）和 `Pebble-<版本>.zip`，连同 `SHA256` 校验和一起发布到 GitHub Releases。

发布版本：

```sh
git tag v1.1.0
git push origin v1.1.0
```

### macOS 不拦截（签名与公证）

签名是可选的，取决于是否配置了仓库 Secrets：

- **未配置证书**：应用为 ad-hoc 临时签名。用户下载后首次打开会被 Gatekeeper 拦截，需要右键 **打开**，或执行 `xattr -dr com.apple.quarantine /Applications/Pebble.app` 去除隔离属性。
- **配置证书**：应用用 Developer ID 在 hardened runtime 下签名，DMG 经 Apple 公证（notarisation）并 staple，用户双击即可运行，无任何拦截提示。这需要付费的 Apple Developer 账号。

在仓库 **Settings → Secrets and variables → Actions** 中配置以下 Secrets 即可启用签名与公证：

| Secret | 说明 |
| --- | --- |
| `MAC_CERTIFICATE_P12` | Developer ID Application 证书（.p12）的 base64 内容 |
| `MAC_CERTIFICATE_PASSWORD` | 上述 .p12 的导出密码 |
| `APPLE_API_KEY_P8` | App Store Connect API 私钥（.p8）内容（推荐） |
| `APPLE_API_KEY_ID` | API Key ID |
| `APPLE_API_ISSUER` | Issuer ID |
| `APPLE_ID` | 无 API Key 时改用：Apple 账号邮箱 |
| `APPLE_APP_SPECIFIC_PASSWORD` | 无 API Key 时改用：应用专用密码 |
| `APPLE_TEAM_ID` | 无 API Key 时改用：团队 ID |

生成 `MAC_CERTIFICATE_P12`：在「钥匙串访问」中选中 *Developer ID Application* 证书及其私钥，右键 **导出** 为 `.p12` 并设置密码，再执行 `base64 -i Certificates.p12 | pbcopy` 粘贴到 Secret。公证凭据二选一：优先使用 App Store Connect API Key（`APPLE_API_KEY_P8` / `APPLE_API_KEY_ID` / `APPLE_API_ISSUER`），否则使用 Apple ID（`APPLE_ID` / `APPLE_APP_SPECIFIC_PASSWORD` / `APPLE_TEAM_ID`）。

也可以在 **Actions → Release → Run workflow** 手动触发，输入不带 `v` 前缀的版本号（如 `1.1.0`）。

## 日常使用

### 记录与整理

在底部输入框中输入内容，按 **Return** 新建笔记，按 **Shift-Return** 换行。新笔记会追加到当前分组末尾。

通过顶部 **⋯ → 新建分组…** 创建分组，点击分组标题将其设为当前分组。点击标题右侧的铅笔按钮可重命名分组，修改名称后点击 **保存**；也可以右键标题重命名或删除分组。删除时可选择保留笔记并移到其他分组，或连同组内笔记一起删除。应用始终保留至少一个分组。

拖动分组标题可调整整个分组的位置：移到目标分组的上半区插到前面，下半区插到后面，蓝色插入线标出放置位置。松手后保存顺序，组内笔记随分组一起移动，可按 **⌘Z** 撤销。

点击卡片选择笔记，**Command-点击** 追加或取消选择，**Shift-点击** 选择连续范围。右键卡片可以执行复制、编辑、移动、合并等操作。拖动卡片时，蓝色插入线和“放到这里”会标出松手后的准确位置：卡片上半区插到前面，下半区插到后面。拖到分组标题可移到组首，拖到最后一张卡片的下半区可移到组末尾；空分组提供虚线放置区域，跨组时目标分组会高亮。松手后才应用移动，可按 **⌘Z** 撤销。

拖动笔记或分组时，将鼠标停在列表顶部或底部边缘即可自动滚动，越靠近边缘滚动越快。移回列表中间或移出列表会暂停滚动，松手或按 **Esc** 取消拖拽后停止。

完成的笔记默认隐藏，可通过 **⋯ → 显示已完成** 再次查看。合并时按界面中的分组与笔记顺序，用空行连接所选内容；复制为编号列表也使用相同顺序。

### 捕获选中文字

在其他应用中选中文字，快速完整按下并松开两次 **Shift**。捕获成功后，内容会保存到当前分组并显示在面板中，来源应用保持焦点。确认没有选区时，Pebble 会打开输入框，方便直接记录。

首次使用跨应用捕获需要开启辅助功能权限：

1. 打开 Pebble 的 **设置 → 捕获**，点击 **启用…**。
2. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许 `Pebble.app`。如果列表中没有应用，可点击 `+` 添加。
3. 返回 Pebble；若权限尚未生效，退出并重新打开应用。

在 **设置 → 捕获 → 录制…** 中，可以设置包含 Command、Option 或 Control 的组合键；点击 **重置** 恢复双 Shift。

Pebble 优先通过辅助功能接口读取选区；目标应用不支持时，会尝试复制选中文字，并在未检测到其他剪贴板修改时恢复原内容。密码字段和系统安全输入状态下不进行捕获。无法捕获时，仍可手动输入或粘贴笔记。

重新构建后，如果辅助功能权限失效，请在系统设置中移除旧条目，再添加当前应用。

### 语言与窗口

在 **Settings → General → Language**（**设置 → 通用 → 语言**）中选择 **English** 或 **简体中文**。首次使用默认英文，切换后立即生效，并在下次启动时保留；笔记内容和分组名称保持原样。

在 **设置 → 窗口** 中调整置顶、外观和登录启动。拖动搜索栏上方或下方的空白区域可以移动面板。

## 快捷键

除全局捕获外，以下快捷键在主面板中使用。卡片操作快捷键在面板获得焦点且未编辑文字时生效；编辑文字时保留系统的复制、粘贴和撤销行为。

| 快捷键 | 操作 |
| --- | --- |
| 双 Shift / 自定义组合键 | 全局捕获选中文字 |
| ⌘N / ⌘F | 聚焦新建输入框 / 搜索 |
| ↑、↓ / Shift-↑、Shift-↓ | 选择卡片 / 扩展选择 |
| ⌘A | 选择全部可见笔记 |
| ⌘C / Shift-⌘C | 复制 / 复制为编号列表 |
| Space | 切换完成状态 |
| Return / ⌘Return | 卡片内编辑 / 在独立窗口编辑 |
| Shift-⌘M | 合并所选笔记 |
| Delete | 删除所选笔记 |
| ⌘Z / Shift-⌘Z | 撤销 / 重做 |
| Esc | 取消编辑、清空搜索或隐藏面板，依当前焦点而定 |

独立编辑窗口中，**Return** 换行，**⌘Return** 保存，**Esc** 取消。

## 本地数据与备份

笔记和分组变更会自动保存。通过 **⋯ → 显示本地文件** 或 **设置 → 本地文件 → 在访达中显示笔记**，可以打开数据目录。

当前默认路径为：

```text
~/Library/Application Support/Pebble/
├── notes.json
└── notes.backup.json
```

`notes.json` 保存当前笔记和分组，`notes.backup.json` 保留前一次有效保存的数据。备份为单份轮换文件，不是完整的版本历史。文件写入采用原子替换；启动时若主文件损坏或缺失，应用会尝试从备份恢复。若无法恢复，会保留原文件并提示错误、停止保存。

从旧版升级时，如果新数据目录尚不存在，应用会自动迁移原有笔记，并沿用原有偏好设置。辅助功能权限和登录启动可能需要重新启用。

需要手动备份或恢复时，先退出 Pebble，再复制或替换数据目录中的文件。窗口、外观、语言和快捷键等偏好由系统单独保存，不包含在笔记 JSON 中。

笔记操作支持当前运行期间最多 100 个撤销快照，连续编辑可能合并为一个步骤。撤销记录不跨重启保留。

也可以在项目目录运行以下命令，指定其他笔记目录：

```sh
"build/Pebble.app/Contents/MacOS/Pebble" --data-dir "/完整路径/笔记目录"
```

自定义目录只改变笔记文件位置，应用设置仍然共用。请勿同时运行多个实例修改同一数据目录。
